PASO 3 — ACTUALIZAR README.md
-----------------------------------------------------------------------
El README.md actual describe el repo como "paquete de documentación para arrancar
con Claude Code". Un dev que clone el repo necesita instrucciones para CORRER el código.
Agregar (o reemplazar) una sección "Cómo arrancar el proyecto":

  ### Requisitos
  - Node.js 22.x (ver .nvmrc — CREAR si no existe)
  - pnpm 9.x: npm install -g pnpm
  - Windows/macOS/Linux con soporte Electron

  ### Instalación
  1. git clone https://github.com/jsinesi-hash/ferreteria-app.git
  2. cd ferreteria-app
  3. pnpm install
  4. pnpm --filter ferreteria-client rebuild:native
     (reconstruye better-sqlite3 contra la versión de Electron del proyecto)

  ### Levantar en dev
  pnpm --filter ferreteria-client dev

  ### Correr tests
  pnpm --filter ferreteria-client test

  ### Seed de datos de ejemplo
  pnpm --filter ferreteria-client seed:dev
  (carga 35 productos, 18 ubicaciones, 8 clientes, ventas y movimientos de caja)

  ### Base de datos
  La base SQLite se crea localmente en userData al arrancar.
  NO se versiona. El seed es el mecanismo de datos iniciales.
